Endless Nightreign - the event scripts are ALREADY COMPILED
===========================================================

Previous versions of this folder shipped only .js sources and asked you to compile them.
You do not need to do that any more: mod/event/ contains the finished files

    m16_00_00_00.emevd.dcx
    m16_10_00_00.emevd.dcx
    m18_00_00_00.emevd.dcx
    m19_00_00_00.emevd.dcx

so the folder can be dropped in and played as-is.

WHAT IF YOU WANT TO EDIT THE SCRIPTS
------------------------------------
The matching .js files sit next to them. Open one in DarkScript3 (Nightreign mode),
edit it, and press Ctrl+S - that writes a new .emevd.dcx. DarkScript3 on Windows writes
KRAK-compressed files, exactly like the retail game files; the shipped ones are DFLT
(zlib) because Oodle compression is not available outside Windows. Both are the same DCX
container and both are read by the game.

TO PLAY
-------
   me3 launch -p EndlessNightreign.me3

and keep nrsc.dll (Seamless Coop) working as usual.
